Unity Input System Breakdown
URP + Mobile
1. Centralized Input Manager Pattern:

Instead of calling Input.GetAxis directly inside character and vehicle scripts, both read from LagosLifestyle.Input.InputManager.Instance.

2. Seamless Mobile & PC Binding:

On PC, standard Keyboard/Mouse and Gamepads drive movement. On Android/iOS, the on-screen Canvas with VirtualJoystick and TouchActionButton feeds the exact same vector to the manager.

3. Canvas Scaler for All Screens:

Canvas Scaler is set to Scale With Screen Size (Reference Resolution: 1920x1080, Match Width/Height: 0.5) with corner anchoring so controls remain fingertip-accessible from compact 5.5" phones to widescreen monitors.

4. Contextual UI Swapping:

When the player walks up to a Danfo minibus and presses Interact, VehicleEntryExit.cs disables the player collider, seats the camera onto the vehicle, and switches on-screen controls to Gas/Brake/Steer/Horn.
